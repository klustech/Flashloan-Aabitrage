# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project or its infrastructure, please report it privately to **security@example.com**. If possible, encrypt your report using our PGP key before sending. Do not disclose details publicly until addressed.

## Bug Bounty Program

We run a bug bounty program. Rewards depend on issue severity. Send a detailed report (reproduction steps, impact) to **security@example.com**.
